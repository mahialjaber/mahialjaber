## 🔬 Portfolio Projects

### 🐍 1. Python Log Parser & Alert Engine
**Tools:** Python · Regex · Pandas · Log Analysis  
Parses Apache/Nginx access logs and automatically flags suspicious patterns — brute force attempts, directory traversal, unusual IP spikes. Outputs a clean incident summary report.

### 📊 2. Splunk SIEM Detection Rules
**Tools:** Splunk · SPL · BOTS Dataset  
A collection of production-ready SPL queries for detecting real threats: failed login storms, Nmap scan fingerprints, suspicious PowerShell execution. Documented with screenshots and analysis.  
📁 *[View Repository →]*

### 🌐 3. Wireshark PCAP Incident Report
**Tools:** Wireshark · Network Forensics · Malware Traffic Analysis

📁 *[View Repository →]*

### ☁️ 4. AWS CloudTrail Threat Detector ⭐ *Featured*
**Tools:** Python · boto3 · AWS CloudTrail · GuardDuty · IAM
